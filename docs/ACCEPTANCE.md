  - `patchLocal(key,{hidden|color})`：直接改手里那份 `/goals` 视图（`_v`），立刻用同一个 `pack()` 重算预览（和首页同一口径），并重排「占环 / 不占环」分组；网络落地后 `load()` 再全量对账。
