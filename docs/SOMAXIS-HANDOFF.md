# Somaxis 会员页接入交接

本轮实现的是独立本地闭环，未修改或部署 Somaxis 正式代码。

## 已有本机只读契约

- `GET /coach/members`：只列出当前虚构教练已获授权的稳定memberId、昵称及授权时间。
- `GET /coach/members/:memberId/summary`：仅允许当前教练绑定的会员；未绑定、其他教练或解除授权均403。只支持GET。
- 返回schemaVersion、generatedAt、timeZone、window(from/to)、recent（有效天数）、rate（百分比）、current（连续天数）、last（最近运动日期）、byType（type/count/distanceM/durationSec）。不返回截图、逐条记录、心率或成员登录身份。
- Somarise成员自己的令牌不能读上述接口。教练会话不能访问成员写操作。

本机预览：`http://127.0.0.1:8787/coach-preview`。点击进入虚构教练预览；需成员先在「我的」完成测试绑定。同源读取、不缓存响应、不把汇总写入浏览器长期存储。每次刷新从当前活动重新计算，不复制会员完整运动数据。

## 正式 Somaxis 的下一步

在已有会员详情页增加「有氧习惯」卡片，由 Somaxis 服务端验证现有可信教练身份和该会员归属，再通过专用服务凭证调用 Somarise 统计服务。不能把本机`/local-coach-session`搬到正式环境，也不能让网页传coachId便获得权限。

应由可信后端签发短效一次性绑定码，成员输入后确认授权，绑定码约束memberId、coachId、audience、nonce及expiry。当前固定DEMO码只用于虚构数据。本轮未读取AppSecret、未连接真实会员数据，亦未声称真实微信认证完成。

会员页状态须区分：尚未授权、已授权暂无运动、已授权有统计、连接暂不可用。未授权不能显示为“0天”，网络错误不能覆盖已有记录。解除授权应使后续读取立即拒绝，正式页面须处理撤销通知或设置短缓存有效期并在展示前校验授权。

## 邀请会员试用前

先完成独立测试后端HTTPS与微信真实身份，再上传体验版并添加体验成员。当前127.0.0.1服务仅电脑可达，不能靠上传代码让会员手机独立使用。正式发布与后台部署是两项不同工作，体验版同样需要可访问的安全后端。
