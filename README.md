# Somarise · 独立本地 MVP

2026-10-26。手机云端体验代码已准备，尚未部署，详见 [手机体验部署说明](docs/MOBILE-TRIAL.md)。原生微信小程序 + Node.js 本机 API + SQLite。零第三方运行依赖，全部数据为虚构演示数据。没有连接 Somaxis 正式环境、云开发、OCR 商业服务或外部运动账户。

## 本地运行

1. 安装 Node.js 22.13+（推荐 24 LTS），在本目录执行 `npm start`。本机服务仅监听 `127.0.0.1:8787`；SQLite 自动保存在 `.local/demo.sqlite`，服务重启保留数据，临时登录令牌会失效。无需 npm install。
2. 在微信开发者工具中导入**本目录**，读取 `project.config.json`；使用测试号/游客模式。若工具不接受 touristappid，请填自己的独立测试 AppID，不使用已有正式小程序配置。
3. 开发者工具本地设置勾选“不校验合法域名、web-view 域名、TLS版本及HTTPS证书”（仅本机调试）。首页进入“虚构用户·小林”；服务未启动时可点刷新重试。
4. 点击“手动记录运动”；填写真实运动日期、时间及对应 UTC 偏移。日期、时间及 UTC 偏移默认按当前设备当地时间填写；补录其他地区的运动时可修改。用户时区用于自然日统计，运动发生时间以带偏移的 ISO 时间保存。
5. 截图入口选择任意小于 2MB 的测试图片，得到**固定模拟数据**，逐项编辑并确认后保存。不会真正识别图片，也不会把图片存进 SQLite。
6. 成员在「我的 / 连接 Somaxis」中修改个人设置、输入本地测试码 `DEMO-MEMBER-001` 并明确同意授权。首页不再提供测试用户切换。
7. 教练本地预览地址：`http://127.0.0.1:8787/coach-preview`。点击进入虚构教练预览，查看已授权汇总；解除授权后刷新立即失去访问权限。
8. `npm test` 运行自动测试。测试数据库只存在内存中，与演示 SQLite 分离。

当前 Codex 环境没有默认 node 命令时，可使用已捆绑的可执行文件：

```sh
/Users/Zhuanz/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node server/http.js
/Users/Zhuanz/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node --test tests/*.test.js
```

## 手机上查看（开发版 / 体验版）

手机不能访问 `127.0.0.1`，所以手机端有两种接法，按需选一种。

**A. 局域网直连本机（最快，手机和电脑要连同一 Wi-Fi）**

```sh
npm run lan        # 自动把本机局域网 IP 写入 miniprogram/config/runtime.js 的 apiBase
npm run start:lan  # 后端改为监听 0.0.0.0，终端会打印手机可访问的地址
```

然后在微信开发者工具里「编译」→「预览」，手机扫码；进入后点右上角「…」→「开发调试」→ 打开调试，再次进入即可（打开调试模式后才跳过域名校验，能请求 `http://192.168.x.x:8787`）。
每次换 Wi-Fi 或重连热点，局域网 IP 会变，重跑一次 `npm run lan` 并重新编译即可。

**B. 微信云开发（体验版正路，手机不依赖电脑）**

按 [手机体验部署说明](docs/MOBILE-TRIAL.md) 开通独立测试环境，把环境 ID 填到 `miniprogram/config/runtime.js` 的 `cloudEnv`，`npm run build:cloud` 后上传并部署云函数 `somactiveApi`。此时手机走 `wx.cloud.callFunction`，不需要域名白名单，也不需要电脑开机。

后端默认仍只监听 `127.0.0.1`；Host 白名单额外放行 RFC1918 私有网段（仅用于上门的真机预览），公网 Host 一律 403。

## 已实现

- 跑步、骑行、游泳统一数据模型，必填/选填字段、计算配速速度、集中配置门槛；私密默认值。
- 截图选择、模拟识别、可编辑草稿、明确确认、失败/超时处理、内存清零、重复图片指纹。
- 月历、月份切换、运动筛选、详情编辑删除；每自然日最多一次有效打卡，本月、当前连续、最长连续、最近28天统计。
- 小组创建、邀请码/分享入口、成员、主动授权的结构化动态；本月/连续榜、并列名次、退出及撤销授权。
- 服务端身份检查、所有权校验、请求白名单、异常字段检查、重复记录拒绝、幂等重试、编辑版本冲突。
- Somaxis 模拟授权绑定/解除、按教练和会员映射只读统计服务；外部平台导入标准化接口。

## 明确限制

- 本地登录仅两名虚构用户；不是已完成的微信正式登录。`server/wechat-identity.js` 提供未接线的 code 换身份适配器，需独立测试 AppID/密钥及服务端映射后才能接入。昵称不作为身份依据；不能跨小程序复用 openid。
- 本服务仅接受本机 Host，无 Origin 或严格同源的请求；提供独立虚构教练汇总预览，演示登录不可用于正式环境。
- 本机 loopback 无法被手机访问；没有进行微信工具编译及真机验收。手机端已准备独立微信云函数连接，通过微信可信身份访问；待开通/关联 Somarise 测试环境后部署验证，不能直接把演示登录服务暴露出去。
- OCR 未开通、未购买、未读取密钥。模拟适配器不创建云端临时文件；真实提供商的数据留存与清理 SLA 尚待核实。清理失败钩子已有测试，云端清理队列/定时任务需选定供应商后实现。
- 小组分享链接在真实微信中的转发、外部 OAuth、Somaxis 真实身份授权均未启用。代码接口可模拟测试，不代表已有外部权限。
- 适合本地小规模验证；读取首页返回该用户完整历史，动态上限50条。生产版需分页、限流、数据库唯一约束与多实例事务、审计及数据删除策略。

## 饮水与抗阻

新建项目的完成方式中现有“抗阻训练”和“饮水”。抗阻确认完成；饮水输入体重、选择35/37.5/40ml/kg目标后分次记录ml，以黑白环形进度展示。每日达到目标计1个有效日，默认每周7个达标日。饮食仍仅为方案，饮水体重和明细未向教练或圈子开放。
